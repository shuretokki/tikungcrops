# data

Everything here is regenerated by the pipelines except `reference/`, and only
`reference/` and this README are tracked in git.

| Path | Tracked | Produced by | Contents |
|---|---|---|---|
| `reference/<aoi>/` | yes (PDFs no) | typed in by hand from publications | optional harvested-area statistics per unit and year, used by `just validate` and loaded into MongoDB `harvests`; format and provenance in its README (Tikung: BPS 2013, 2020) |
| `external/gadm/` | no | `pipeline.aoi`, downloaded on first use | GADM 4.1 admin boundaries (free for non-commercial use, not redistributable) |
| `bronze/sentinel/<aoi>/` | no | `just sentinel AOI START END` | one parquet per month: cell x acquisition date x sensor (S2 NDVI/LSWI/clear share, S1 VV/VH dB), plus `cells.parquet` (100 m cropland cells, their unit and coordinates) |
| `bronze/sentinel/<aoi>/paddy.parquet` | no | `just paddy AOI` | share of each cell inside official paddy fields (Lahan Baku Sawah, BIG) |
| `external/lbs/` | no | `just paddy AOI` | Lahan Baku Sawah polygons for the AOI (redistribution terms not stated) |
| `silver/sentinel/<aoi>.parquet` | no | `just silver AOI` | cleaned per-cell series on a 5-day calendar |
| `gold/sentinel/<aoi>_seasons.parquet` | no | `just gold AOI` | one row per cell per season: flooding, green-up, peak, harvest dates, rice flag |
| `gold/sentinel/<aoi>_forecast_eval.csv` | no | `just forecast AOI` | harvest-date forecast scores per held-out year (model vs baseline error, range coverage) |
| `gold/sentinel/<aoi>_validation*.csv` | no | `just validate AOI` | satellite vs reference area per year (r, ratio) and per unit |
| `gold/sentinel/<aoi>_units.parquet` | no | `just gold AOI` | per unit, year and season (MT1-MT3): area, rice area, flooding and harvest windows; loaded into MongoDB `planting_seasons` |
| `gold/sentinel/<aoi>_intensity.parquet` | no | `just gold AOI` | per unit and year: seasons per hectare of paddy (all crops and rice only), paddy share with 3+ seasons, full-year flag; loaded into MongoDB `cropping_intensity` |
| `bronze\|silver/chirps/<aoi>_*.parquet` | no | `just chirps AOI` | CHIRPS v3 monthly rainfall per unit, 1981-now, with 1991-2020 normals, anomalies and annual totals |
| `silver/soilgrids/<aoi>_*.parquet` | no | `just soilgrids AOI` | SoilGrids 2.0 properties (0-30 cm) per cell and median per unit, read from ISRIC's global rasters |
| `relational.db` | no | dashboard forms (`jotosanur_agri.store`) | SQLite: users, destinations, distribution records entered by the mitra |
| `web/<aoi>/*.json` | no | `just web AOI` | static JSON for the public web app: cells with current stage, seasons, cropping intensity, outlook, rain, validation (see `pipeline.export_web`) |

`<aoi>` is the area slug: ISO3 plus the full GADM name path, e.g. `idn-jawatimur-lamongan-tikung`
for `Lamongan/Tikung`, or the file name for a GeoJSON AOI.

## Rebuild

```sh
just sentinel Lamongan/Tikung 2019-09 2020-12   # satellite bronze for a month range
just setup Lamongan/Tikung                      # paddy mask, soil, rain, silver, gold, validation, MongoDB
just monthly Lamongan/Tikung                    # later: last month only, then rebuild
```

Sentinel extraction takes about 30 s per month for Kecamatan Tikung (13 desa); silver and
gold take seconds.
